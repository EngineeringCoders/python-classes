# Setup Guide

## Prerequisites

Install Python 3.12 or above, Git, and a code editor.

Check Python:

```bash
python --version
```

## Clone and switch branch

```bash
git clone https://github.com/EngineeringCoders/python-classes.git
cd python-classes
git checkout python-modules-student-logistics
```

## Open the project

```bash
cd student-logistics/python-modules/starter_project/student_toolkit_pro
```

## Create environment

```bash
python -m venv .venv
```

Activate on macOS or Linux:

```bash
source .venv/bin/activate
```

Activate on Windows:

```bash
.venv\Scripts\activate
```

## Install dependencies

```bash
pip install -r requirements.txt
```

## Run the app

```bash
python main.py
```

Or:

```bash
python -m student_toolkit
```

## Run tests

```bash
pytest
```
