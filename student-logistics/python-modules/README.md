# Python Modules Class - Student Logistics

Welcome to the Python Modules class. This learning pack is designed to help you understand how Python code is organized into modules and packages by building a small real-world CLI project called **Student Toolkit Pro**.

## What you will build

You will build a modular command-line application that can:

1. Add student records
2. Calculate percentage and grade
3. Check attendance eligibility
4. Pick a random student or generate a module question
5. Save and load data using JSON
6. Generate a class report
7. Export a CSV report
8. Log application activity
9. Test modules independently

## Learning outcomes

By the end of this class, you should be able to:

- Explain what a Python module is.
- Differentiate module, package, library, and framework.
- Use standard library modules such as `json`, `csv`, `random`, `pathlib`, `statistics`, and `logging`.
- Create user-defined modules.
- Use import styles correctly.
- Understand `sys.path`, `sys.modules`, `__pycache__`, `__name__`, and `__main__.py`.
- Organize code into packages using `__init__.py`.
- Build a modular CLI project.
- Run tests using `pytest`.
